# /speckit.lx.report — отчёт о реализации

Сгенерируй `specs/NNN-…/implementation_report.md` для текущей задачи (проза — русская),
не трогая git. Источник: `spec.md`, `plan.md`, `tasks.md` и фактический дифф.

Секции отчёта:
- метастрока `**Дата:** YYYY-MM-DD · **Статус:** <M|S|C>`;
- `## Итог` — что закрыто;
- `## Изменения` — **Новые файлы** / **Правки**, полные пути + функции;
- `## Решения` — обоснование неочевидных выборов и отвергнутых альтернатив;
- `## Проверки` — вывод `go build/test/vet` (+ доменные проверки, если есть);
- `## Безопасность` — секреты/креды не в репозитории;
- `## Вне scope / дальше` — отложенное.

Отчёт обязателен для реализованных задач; для чисто плановых (только SPEC) — не требуется.
Это один из шагов `/speckit.lx.close`; вызывай отдельно, когда нужен только отчёт.
