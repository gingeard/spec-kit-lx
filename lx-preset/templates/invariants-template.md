# INVARIANTS [NNN] — [SHORT_TITLE]

<!--
  LX invariants — производный документ спеки (как plan/tasks/report). Выносится, когда
  инвариантов ≥3: разгружает spec и даёт МАШИННО-ЧИТАЕМЫЙ контракт для тестов.
  spec.md держит терсный ИНДЕКС (`INVn — имя` + ссылка сюда); полные записи — здесь.
  Пустой `тест:` (`—`) = дыра покрытия. `git blame Код` даёт коммит (хешей не держим).
  Каждый инвариант, затрагивающий код, несёт парный маркер `// SPEC NNN invariant: …`.

  EARS-СЛОВАРЬ для контракта (заимствовано из Kiro/EARS — форсит проверяемость):
    событие        → WHEN  [триггер]            THEN system SHALL [обязательство]
    guard/ошибка   → IF    [невалидное/сбой]    THEN system SHALL [поведение]
    непрерывное    → WHILE [длящееся условие]        system SHALL [поведение]
    режим/контекст → WHERE [конфиг/платформа]        system SHALL [поведение]
    запрет         → … SHALL …, NEVER [чего делать нельзя]
  Контракт в EARS = готовый arrange/act/assert будущего теста.
-->
